# cpu-monitor

A small utility for viewing CPU load/temperature through the tray icon.
It is possible to change colors =)


### Python 3.14

### Launch via `pip' (unstable)

    pip install -r requirements.txt
    python main.py

### Launch via `uv`

    uv sync
    uv run -m src.main
